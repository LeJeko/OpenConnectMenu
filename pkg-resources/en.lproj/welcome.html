VPN OpenConnect

This menu bar app connects to an AnyConnect-compatible VPN using openconnect, without asking for an administrator password on every connection.

Requirement

openconnect must be installed with Homebrew. If it is not, open Terminal and run:

brew install openconnect

Homebrew is available from https://brew.sh.

After installation

  1. Open VPN OpenConnect from the Applications folder.
  2. Allow the helper in System Settings › General › Login Items & Extensions.
  3. Choose Approve openconnect… in the menu (administrator password, once).
  4. Enter your username, password and TOTP secret in Settings…
