VPN OpenConnect

Cette app de barre de menu se connecte à un VPN compatible AnyConnect avec openconnect, sans redemander de mot de passe administrateur à chaque connexion.

Prérequis

openconnect doit être installé avec Homebrew. S'il ne l'est pas, ouvrez le Terminal et lancez :

brew install openconnect

Homebrew s'installe depuis https://brew.sh.

Après l'installation

  1. Lancez VPN OpenConnect depuis le dossier Applications.
  2. Autorisez l'assistant dans Réglages Système › Général › Éléments de connexion et extensions.
  3. Choisissez Approuver openconnect… dans le menu (mot de passe administrateur, une seule fois).
  4. Renseignez identifiant, mot de passe et secret TOTP dans Réglages…
